# Security reports

Email security-sensitive findings to dunn0dud3@gmail.com rather than posting
private diagnostic data in public. Include app version, affected code/path,
reproduction steps, and impact. Redact UIDs, serial numbers, keys, and personal data.

Ordinary compatibility problems can use the bug-report issue template. Emula
reproduces NFC-A UIDs and does not add authentication to UID-only access systems.
