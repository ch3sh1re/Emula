# Public history

This copy was prepared from private Git history before its first GitHub
publication. Ordering, author dates, committer dates, and messages are retained.
Commit IDs changed because private content was removed and author/committer
identity was standardized to `dunno <dunn0dud3@gmail.com>`.

Cleanup removes internal prompts/task material, raw reports, local build evidence,
signing/release artifacts, store-production material, and captured third-party
firmware files from every retained revision. Some commits consequently have empty
source diffs; they remain to preserve chronology.

The first retained commit is an Emula 1.0.9 release snapshot dated October 5, 2026.
It already includes `LegacyNfcController.defaultConfig()` and
`POST_RESUME_REAPPLY`. Earlier development is not represented by individual
commits. The October 19 snapshot includes work documented/tested earlier,
including the watch confirmation dated October 17; those events were not
reconstructed as backdated commits.

The [public Emula announcement](https://www.reddit.com/r/NFC/comments/1wvof7a/i_built_emula_nfc_uid_emulation_app_on_android_15/)
provides context outside Git. Commit dates are recorded metadata, not independent
proof of first publication. Opening this repository does not change its GitHub
publication date or reconstruct missing history.
